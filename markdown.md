# 3.- Lenguaje de marcas: Markdown

Markdown es un lenguaje de marcado ligero creado en 2004 por John Gruber, con contribuciones clave de Aaron Swartz. Un lenguaje de marcado es un sistema que utiliza etiquetas o caracteres especiales para definir la estructura y el formato de un texto, a diferencia de los editores WYSIWYG (What You See Is What You Get) como Microsoft Word, donde aplicas el formato mediante botones y menús.

El objetivo de diseño de Markdown es la máxima legibilidad: un documento formateado con Markdown debe poder publicarse tal cual, en texto plano, sin que parezca que ha sido marcado con etiquetas HTML complejas. Originalmente, se diseñó como una herramienta de conversión de texto a HTML para escritores web.

**Ventajas y características:**

* **Portabilidad:** Al ser texto plano (archivos `.md`), puede ser abierto y editado desde cualquier sistema operativo con cualquier editor básico (Notepad, Vim, Nano) o editores avanzados (Visual Studio Code, Typora).
* **Velocidad:** Permite a los desarrolladores escribir documentación sin separar las manos del teclado para usar el ratón.
* **Estandarización:** Se ha convertido en el estándar de facto para escribir archivos `README`, wikis de proyectos, documentación de APIs, foros (como Reddit o Stack Overflow) e incluso aplicaciones de mensajería (como Discord o Telegram).

Aunque existe una especificación original, con el tiempo han surgido "sabores" (flavors) de Markdown que añaden funcionalidades adicionales. El más famoso es GitHub Flavored Markdown (GFM), que incluye soporte nativo para tablas, listas de tareas (checkboxes), y resaltado de sintaxis para bloques de código de múltiples lenguajes de programación.
