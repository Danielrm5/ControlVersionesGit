Para trabajar con estas herramientas es necesario conocer varios términos clave. Un repositorio es como una carpeta en la que se encuentran archivados los ficheros de tu proyecto (código, documentación) y puede ser público o privado. Una rama es una copia del contenido; la rama master contiene el proyecto original, mientras que una rama remota es una copia paralela para trabajar sin afectar al original.   Hacer un Clone es copiar el proyecto original para trabajar en local, mientras que un Fork es una copia creada en tu perfil de GitHub para trabajar online. Al hacer cambios, los guardamos como registros llamados Commits. Para enviar estos cambios a la rama principal hacemos un Push, y mediante un Pull Request solicitamos desde la interfaz que se apruebe nuestra aportación. Finalmente, el Merge es la integración de esos cambios aprobados, haciendo que ambas ramas vuelvan a ser idénticas.
